## Common Mobile Issues to Fix

### Typography
- Ensure text is readable (minimum 14px for body text on mobile)
- Headers should scale appropriately
- No text truncation unless necessary

### Spacing
- Adequate touch targets (minimum 44x44px)
- Proper padding/margins for mobile screens
- No horizontal scrolling

### Layout
- Cards/buttons should be full-width or properly sized on mobile
- Grid layouts should collapse to single column on mobile
- Navigation should be accessible

### Interactive Elements
- Buttons should be easily tappable
- Forms should be mobile-friendly
- Dropdowns/selects should work well on mobile
