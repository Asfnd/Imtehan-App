# Virtual Subject Mapping: 11 Subjects → 23 Tests

## How It Works

Same MCQ tagged with different subject names for different exams.

**Example:**
```
Question: "Quaid-e-Azam presented 14 points in which year?"

Used in:
- CSS Exam → Subject: "Pakistan Affairs"
- PPSC Clerk → Subject: "Pakistan Studies"
- Banking Exam → Subject: "General Awareness"
- NTS GAT → Subject: "Pakistan History"

Same MCQ, 4 different exams ✓
```

## Database Implementation

### Single Table with Virtual Subjects Array:

```sql
CREATE TABLE mcqs_master (
  id BIGSERIAL PRIMARY KEY,
  question TEXT,
  option_a TEXT,
  option_b TEXT,
  option_c TEXT,
  option_d TEXT,
  correct_answer CHAR(1),

  -- Source metadata
  source_subject TEXT,          -- 'Pakistan_Studies'
  source_folder TEXT,           -- 'extracted', 'most_repeated', 'most_important'

  -- Virtual subjects for multi-exam support
  virtual_subjects TEXT[],      -- Array: ['Pakistan Studies', 'Pakistan Affairs', 'General Awareness']

  -- Flags
  is_most_repeated BOOLEAN,
  is_most_important BOOLEAN,

  created_at TIMESTAMP
);

CREATE INDEX idx_virtual_subjects ON mcqs_master USING GIN(virtual_subjects);
```

## Mapping Script (Auto-tag Virtual Subjects)

### Rule-based Mapping:

```python
def map_virtual_subjects(source_subject):
    mapping = {
        'Pakistan_Studies': [
            'Pakistan Studies',      # PPSC, FPSC, ETEA, Police
            'Pakistan Affairs',      # CSS, PMS
            'General Awareness',     # Banking (partial)
            'Pakistan History'       # NTS
        ],
        'General_Knowledge': [
            'General Knowledge',     # PPSC, FPSC, CSS, PMS
            'General Awareness',     # Banking
            'General Ability',       # NTS, Army, Navy, PAF
        ],
        'Everyday_Science': [
            'Everyday Science',      # PPSC, PMS, CSS
            'General Science',       # FPSC, ETEA, Army/Navy/PAF
            'Science & Technology'   # Banking (partial)
        ],
        'Current_Affairs': [
            'Current Affairs',       # All exams use same name
        ],
        'Basic_Computer': [
            'Computer Science',      # PPSC, FPSC, ETEA
            'IT & Computer',         # Banking
            'Computer Knowledge',    # NTS
            'ICT'                    # CSS (partial)
        ],
        'General_Math': [
            'Mathematics',           # PPSC, PMS, CSS, FPSC
            'Arithmetic',            # CSS (combined)
            'Quantitative Aptitude', # Banking, NTS
            'Quantitative'           # Army/Navy/PAF
        ],
        'English': [
            'English',               # Universal - all exams
        ],
        'Urdu': [
            'Urdu',                  # PPSC, PMS, FPSC, ETEA
        ],
        'Islamiat': [
            'Islamic Studies',       # CSS, PMS
            'Islamiyat',            # PPSC, FPSC, ETEA, Army/Navy/PAF
        ],
        'General_Geography': [
            'Geography',             # CSS, PMS, PPSC, FPSC
        ],
        'Ethics_Civics': [
            'Ethics',                # CSS, PMS
            'Civics',               # PPSC (partial)
            'Ethics & Civics'       # Combined
        ]
    }

    return mapping.get(source_subject, [source_subject])

# Apply to all MCQs
import pandas as pd

df = pd.read_csv('Pakistan_Studies.csv')
df['virtual_subjects'] = df['source_subject'].apply(map_virtual_subjects)
```
