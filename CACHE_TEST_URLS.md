## 🔤 **Fonts (.woff, .woff2, .ttf)**

### **Next.js Auto-generated Fonts:**
These are served from `/_next/static/` path:

```
https://imtehan.com/_next/static/media/[font-hash].woff2
https://imtehan.com/_next/static/media/[font-hash].woff
```

**Note:** Font hashes are auto-generated by Next.js. To find actual URLs:

1. Open https://imtehan.com in browser
2. Open DevTools → **Network** tab
3. Filter by `.woff2` or `.woff`
4. Copy the full URL you see

**Example output (yours will have different hash):**
```
https://imtehan.com/_next/static/media/2aaf0e49c7e01e37-webfont.woff2
https://imtehan.com/_next/static/media/a5e07b5a5c6d83df-webfont.woff
```

### **Test Command (once you have the URLs):**
```bash
curl -I "https://imtehan.com/_next/static/media/[your-actual-hash].woff2"
curl -I "https://imtehan.com/_next/static/media/[your-actual-hash].woff2"

# Look for: cf-cache-status: HIT
```

## 📊 **What You Should See**

### **✅ Cache HIT (Good):**
```
cf-cache-status: HIT
```

### **✅ Cache MISS (Normal on first request):**
```
cf-cache-status: MISS
```
After second request within cache window, should be `HIT`

### **✅ Cache BYPASS (Correct for dynamic data):**
```
cf-cache-status: BYPASS
```

### **❌ If Not Showing cf-cache-status Header:**
- Domain might not be proxied (orange cloud) in Cloudflare DNS
- Cache rules might not be deployed yet
- Wait 5 minutes for rules to propagate

## 🔍 **How to Check in Browser**

1. **Open DevTools** (F12 or Right-click → Inspect)
2. Go to **Network** tab
3. Reload page
4. Look for requests to your static files
5. Click on any request
6. Go to **Response Headers** tab
7. Look for: `cf-cache-status: HIT` or `MISS`
